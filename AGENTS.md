## Architectural Principles

1. **Deep Modules Over Shallow Pass-Throughs**: Every module must have a small, intuitive interface that conceals rich implementation complexity.
2. **Ubiquitous Language**: Strictly adhere to `GLOSSARY.md`. Never use unapproved synonyms or casual terminology.
3. **Swiss Editorial Visual Standards**: 0px architectural geometry, hairline borders, uncropped physical artboards, and strict typography.
4. **Imperial Plum-Violet Visual World**: Velvet plum backgrounds (`#0D011A` / `#1A0033`), ultraviolet white text (`#FAF7FF`), lavender editorial body (`#C4B8D8`), and electric lilac accents (`#C882FF`).
