## Integration Workflow for Next.js App Router

### Step 1: Locate Component
Find the component in `references/react-bits/src/ts-default/<Category>/<Name>/`.
Copy both `<Name>.tsx` and `<Name>.css` (or adapt to your project's styling tokens).

### Step 2: Ensure Client Component Directive
All interactive animation components MUST start with:
```tsx
'use client';
```

### Step 3: Handle Canvas / WebGL / Dynamic Import
For components that use Three.js, OGL, or direct canvas DOM contexts (`Balatro`, `LiquidChrome`, `FluidGlass`, `Lanyard`, `Particles`), prevent SSR hydration mismatches by wrapping in `next/dynamic`:
```tsx
import dynamic from 'next/dynamic';

const LiquidChrome = dynamic(
  () => import('@/presentation/components/animations/LiquidChrome'),
  { ssr: false }
);
```

### Step 4: Wire to Project Design Tokens
Replace raw hex values with CSS variables or Tailwind tokens:
```css
/* Before */
background: #111111;
color: #ffffff;
--spotlight-color: rgba(255, 255, 255, 0.2);

/* After — BrandMania tokens */
background: var(--bg-surface);
color: var(--text-primary);
--spotlight-color: rgba(112, 0, 255, 0.25); /* Brand Imperial Purple */
```
