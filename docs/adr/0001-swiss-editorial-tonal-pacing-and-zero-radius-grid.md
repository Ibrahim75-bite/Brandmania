# 0001. Swiss Editorial Tonal Pacing and Zero-Radius Grid

**Context**: High-ticket B2B brand advisory ($700,000+ commercial threshold) demands instant visual authority and differentiation from generic AI-generated SaaS platforms that rely on rounded pill cards, neon gradient blurs, and template layouts.

**Decision**: We committed strictly to a Swiss-editorial monograph layout featuring strict 0px architectural corners, 1px solid hairline grids (`rgba(255, 255, 255, 0.12)` on obsidian `#070709`, `rgba(9, 8, 12, 0.14)` on alabaster `#F3F0EA`), weight-400 `Instrument Serif` display typography, `JetBrains Mono` tabular index coordinates, and uncropped physical artboard presentations.

**Consequences**: Standard component libraries with default border radiuses cannot be used out of the box, requiring custom architectural CSS tokens; however, this creates a distinctive, defensible visual identity that immediately communicates institutional rigor to prospective executive clients.
